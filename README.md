# ListHub

A modern, redesigned version of Craigslist — built with vanilla HTML, CSS, and JavaScript, powered by Firebase Authentication and Firestore.

## 🌟 Features

- **Modern UI** — Dark theme with emerald green + amber accent palette
- **Firebase Auth** — Email/Password + Google Sign-In
- **OTP Verification** — Email and phone OTP flow on signup
- **Cloud Firestore** — User profiles stored in real-time database
- **Responsive** — Works on all screen sizes

## 📁 Project Structure

```
craigslist-redesign/
├── index.html          # Home page
├── login.html          # Login page (Firebase Auth)
├── signup.html         # Signup page (Firebase Auth)
├── firebase.js         # Firebase configuration & helpers
├── styles.css          # Global stylesheet
└── ...
```

## 🚀 Getting Started

1. Clone the repository
2. Serve with any static server (e.g. `npx serve .` or VS Code Live Server)
3. Open `http://localhost:3000`
